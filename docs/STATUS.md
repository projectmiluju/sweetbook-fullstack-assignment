## 최근 변경

- 부트캠프 수료 포트폴리오 북 서비스의 PRD를 승인 상태로 정리
- SweetBook API 채택 범위를 `Books`, `Orders`, `BookSpecs`, `Credits`로 확정
- 이슈/PR 템플릿과 PHASE 기반 이슈 구조 정리
- 프론트엔드/백엔드 분리 스택을 `Next.js + Express + TypeScript`로 결정
- 패키지 매니저를 `pnpm workspace`로 전환하고 루트 실행 스크립트를 정리
- `README` 실행 가이드를 `pnpm` 기준으로 갱신
- `#29`에서 Foundation Set 5개 화면의 1차 기준선을 코드에 반영
- API 서버가 꺼져 있어도 프론트엔드가 더미 데이터로 동작하도록 fallback 처리 추가
- Foundation Set 전용 UI 스펙과 디자인 가이드를 별도 문서로 정리
