# ADR-006: UI 전면 리디자인 — SweetBook에서 Foliocraft로

**일자:** 2026-04-08
**상태:** Accepted

## 맥락 (Context)

Foundation Set 1차 기준선(#29) 이후 구현된 UI가 따뜻한 베이지/브래스 톤의 디자인이었으나, 전체적인 완성도가 기대에 미치지 못했다.
프로젝트 이름도 "SweetBook"에서 포트폴리오 북 제작이라는 목적을 더 직접적으로 반영하는 이름으로 바꾸기로 했다.

SKILL.md(Supanova Redesign Engine)의 감사 기준을 적용해 기존 디자인의 문제점을 체계적으로 진단했다:
- 보라/블루 계열 악센트는 "AI 디자인 지문"으로 진단
- 헤드라인 크기·CTA 크기·섹션 패딩이 랜딩페이지 기준 미달
- hover/active 피드백과 스프링 전환 미적용
- `text-wrap: balance`, `scroll-behavior: smooth` 등 한글 타이포 최적화 누락

## 고려한 선택지

### 선택지 A: 기존 Brass & Vellum 톤 유지, 부분 보정
- 장점: 변경 범위 최소화, 기존 디자인 문서 재사용 가능
- 단점: 근본적인 완성도 문제 해결 안 됨, 이미 여러 차례 부분 수정을 시도했으나 만족스럽지 않았음

### 선택지 B: 다크 모드 기반 전면 리디자인
- 장점: 시각적 차별화, 에디토리얼 톤에 적합
- 단점: 포트폴리오 북이라는 "인쇄물" 맥락과 다크 모드가 어울리지 않음, 접근성 고려사항 증가

### 선택지 C: 라이트 모드 + SKILL.md 기준 전면 리디자인 ← **채택**
- 장점: SKILL.md의 체계적 감사 기준 적용, 인쇄물과 어울리는 밝은 톤, 한글 타이포 최적화 포함
- 단점: 전체 18개 파일 수정 필요, 디자인 문서 3개 재작성 필요

## 결정 (Decision)

**선택지 C**를 채택했다. 구체적 변경:

| 항목 | Before | After | 근거 |
|------|--------|-------|------|
| 프로젝트명 | SweetBook | **Foliocraft** | "포트폴리오 + 제작"의 의미를 직접 전달 |
| 악센트 | `#8A6A2F` (브래스) | **`#b45309`** (앰버-700) | SKILL.md: 보라/블루 금지, 과채도 금지. 출판/에디토리얼 톤 |
| 디스플레이 폰트 | Geist → Cormorant Garamond | **Outfit** | SKILL.md 권장 목록. 한글(Pretendard)과 조합 시 weight 밸런스 양호 |
| 바디 폰트 | Pretendard | **Pretendard** (유지) | SKILL.md 1순위 권장 |
| 배경 | `#F5F1E8` (베이지) | **`#fafaf9`** (warm stone) | stone 계열 통일, 순백 카드와 대비 확보 |
| 그림자 | 브래스 톤 | **stone 톤** `rgba(120,113,108,0.08)` | 배경 hue와 일치하는 틴트 |
| 트랜지션 | `300ms ease` | **`400ms cubic-bezier(0.16,1,0.3,1)`** | SKILL.md: 스프링 기반 전환 |
| CTA 크기 | `px-6 py-3 text-sm` | **`px-8 py-4 text-lg`** | SKILL.md: CTA 최소 기준 |
| 섹션 패딩 | `py-16` | **`py-20 md:py-32`** | SKILL.md: 랜딩페이지 최소 기준 |
| hover | `translate-y` | **`scale-[1.02]`** + 글로우 그림자 | SKILL.md: hover 피드백 |

## 결과 (Consequences)

- 긍정적: SKILL.md 감사 기준 전항목 충족. 디자인 문서(토큰/컴포넌트/와이어프레임) 코드와 동기화 완료. 컴포넌트 테스트 9개 신규 추가(happy-dom).
- 부정적: 기존 Stitch 프로토타입 3개(운영자 대시보드, 기수 상세, 책 종류 선택)가 구버전 디자인 기준이라 참고 가치 소멸.
- 리스크: 로고가 SVG 인라인으로만 존재. favicon 미적용.

## 되돌릴 조건 (Reversal Triggers)

- 프로젝트명 "Foliocraft"가 상표 문제를 일으키는 경우
- 앰버 악센트가 접근성 대비(WCAG AA) 기준을 충족하지 못하는 경우 (현재 흰 배경 위 `#b45309`는 4.56:1로 AA 통과)
