# 개발 일지: 기수별 수료생 목록 로딩/빈 상태 처리 (#7)

**일자:** 2026-04-06
**관련 버전:** v0.1.0
**관련 역할:** build, qa

## 배경 (Context)

`#6`에서 확립한 패턴(loading.tsx + 빈 상태 분기)을 `/cohorts/[cohortId]` 페이지에도 동일하게 적용했다. 이슈 #7의 DoD 중 "기수 선택에 따라 수료생 목록이 바뀝니다"는 동적 라우트 `[cohortId]`가 이미 처리하고 있었고, 미충족 항목은 로딩/빈 상태뿐이었다.

## 문제 (Problem)

`/cohorts/[cohortId]/loading.tsx` 미존재 → 데이터 로딩 중 빈 화면.
`cohort.students.length === 0` 시 아무것도 렌더링되지 않음.

## 최종 해결 (Resolution)

- `apps/web/src/app/cohorts/[cohortId]/loading.tsx` 신규 작성 (대시보드 스켈레톤과 동일 패턴)
- `apps/web/src/app/cohorts/[cohortId]/page.tsx` 빈 상태 분기 추가

`#6`과 완전히 동일한 구현 패턴이므로 별도 기술 결정 기록(ADR)은 작성하지 않았다.

## QA: getCohort() 테스트 확장

기존 `api.test.ts`에 `getCohort` describe 블록을 추가했다 (5개 테스트).

- API 성공 → 수료생 포함 기수 상세 반환 확인
- API 실패 → mock fallback 확인
- mock에 없는 ID → `"기수를 찾을 수 없습니다."` throw 확인
- 수료생 필수 필드 구조 검증
- `studentCount`와 실제 `students.length` 일치 검증 (데이터 무결성)

총 테스트: 18개 (기존 13 + 신규 5), 전부 통과.

## 배운 것 (Lessons Learned)

`#6` 패턴을 확립했기 때문에 `#7`은 삽질 없이 완료됐다. 동일 패턴의 반복 구현 시 첫 번째 이슈에서 패턴을 제대로 잡아두는 것이 이후 이슈의 속도를 결정한다.
